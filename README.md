# VOUVRY GENÈVE — Swiss Luxury Haute Horlogerie Website

A fully responsive, production-quality luxury watch brand e-commerce website created with **React**, **Tailwind CSS**, and **modern JavaScript**. Inspired by Swiss Haute Horlogerie and the uploaded reference screenshots, the project crafts an original, authentic Swiss luxury watch brand identity: **VOUVRY GENÈVE (Swiss Made Since 1888)**.

## 🛠️ Interactive Modals & Drawers

1. **Product Details Modal:**
   - Multi-image gallery with hover macro zoom.
   - Complete technical specifications table (Diameter, Thickness, Case Alloy, Crystal, Calibre, Power Reserve, Water Resistance, Strap, Warranty).
   - Quantity selector and direct Add to Bag / Wishlist.
   - Direct button to schedule private boutique fitting.
2. **Wishlist Slide-out Drawer:**
   - Slide-in panel from the right displaying all saved timepieces.
   - One-click transfer to shopping bag or removal.
   - Synchronized counter badge in navigation bar.
3. **Shopping Bag Drawer:**
   - Real-time cart calculation in Indian Rupees (₹).
   - Quantity adjustment (`+` / `-`).
   - Free insured express delivery notice.
   - "Proceed to Luxury Checkout" simulation with generated VIP Order ID.
4. **Global Search Modal:**
   - Instant search across catalog and new releases by collection, movement, size, or style.

## 🚀 How to Run the Website

### Option 1: Direct Double-Click (Zero Setup Required)
You can directly double-click `index.html` from Windows Explorer to open and use the entire website in Google Chrome, Microsoft Edge, or Mozilla Firefox.

### Option 2: Run with Built-in Local Server
Open PowerShell in the project directory:
```powershell
agy-node server.js
```
Then visit:
```
http://localhost:5173
```
